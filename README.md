# 🍜 Joi Aai Axom Restaurant Menu

A modern, responsive digital restaurant menu website for **Joi Aai Axom**, an Indo-Chinese and Street Food restaurant based in Guwahati, Assam.

## ✨ Features

- 📱 Fully Responsive Design (Mobile, Tablet & Desktop)
- 🍜 Category-wise Menu Navigation
- 🥗 Veg / Non-Veg Filtering
- 💰 Dynamic Pricing Display
- ⭐ Restaurant Information Section
- 🎨 Premium Assamese-inspired UI
- 📌 Sticky Navigation for Mobile Users
- ⚡ Fast and Lightweight
